# Palee theme: every UI element and its parts

Palee wears **one theme** for every account type and role: the vendor's
platform console, gym owners, staff and coaches, solo coaches, athletes and
members, the kiosk and the public pages alike. It is the brand palette from
[BRAND.md](BRAND.md) in a light variant, **Frost** (the default), and a dark
one, **Graphite** ("Graphite Night"). Anyone may switch to dark in
Settings › Theme, the same way whatever their role; no role, gym or
organization chooses a theme, and gym brand colours never tint the app or
anything it renders (a gym shows its identity through its logo and photos).

## One source

Every colour, shadow and font is defined once, in
[`apps/web/src/lib/theme.ts`](../../apps/web/src/lib/theme.ts). Everything
else reads from it:

| Consumer | How it gets the theme |
| --- | --- |
| Web app (all pages, B2B and member) | The root layout inlines the CSS variables generated by `themeStylesheet()`; components use `var(--token)` only |
| Native form controls, scrollbars, selection | `apps/web/src/app/globals.css` maps the variables onto the elements (no literals) |
| Canvas, maps, rich-text marks | `readToken(name)` reads the current value |
| Share images (Open Graph) | `SHARE_CARD_TOKENS` (the dark variant) |
| PDF and ODT exports, invoices, QR codes | `PRINT_TOKENS` (paper is light) |
| PWA manifest, browser `theme-color` | `APP_THEMES[DEFAULT_THEME_SLUG]`; `applyTheme()` updates `theme-color` |
| Android and iOS shells, widgets, offline page, Capacitor splash | Files generated by `npm run theme:native` (see `src/lib/native-theme.ts`) |
| API emails, receipts and Apple and Google Wallet passes | `Palee.BrandPalette`, generated by the same command |

To re-dress the app, edit `theme.ts`, run `npm run theme:native` in
`apps/web`, and commit. Four tests keep this honest:

- `theme-guard.test.ts` fails on any colour literal (hex, `rgb()`/`hsl()`,
  named colours, Tailwind palette classes, jsPDF RGB channels) or any unknown
  CSS variable anywhere in `apps/web/src` outside `theme.ts`.
- `theme.test.ts` checks WCAG contrast for every text and graphic pair in
  both variants, and that both define the same tokens.
- `native-theme.test.ts` fails while any generated native or API file is stale.
- `apps/api/test/palee/brand_palette_guard_test.exs` fails on any colour
  literal in the API outside `Palee.BrandPalette`.

Token names are camelCase in `theme.ts` and kebab-case as CSS variables
(`panelRaised` → `--panel-raised`).

## Brand roles

| Role | Token | Use it for | Never for |
| --- | --- | --- | --- |
| Dojo (primary) | `--primary`, `--primary-strong`, `--primary-contrast` | Actions and navigation: buttons, links, the active tab, selected chips, booking, charts | Decoration |
| Spark | `--spark`, `--spark-contrast` (`lib/spark.ts`: `SPARK_ACTIVE_STYLE`, `SPARK_CREATE_STYLE`, `SPARK_GO_STYLE`) | Energy: what is alive now (LIVE, New, WOD tags, today in calendars, the streak, live challenge progress on a deep track, Active / Connected / Published status pills, the done steps of a wizard), "+ New / + Add" create chips, and go-now actions (ADR-182: Check in, Start / Resume workout ▶, Join a club, group or channel, Share or export, the date picker's Today). Always a fill with dark text (`--spark-contrast`) | Text on the page; save, submit and confirm actions (Dojo); next to Heat; alone with Graphite |
| Heat | `--heat`, `--heat-contrast` | Emotion: kudos, PRs, comebacks, the "hard moment" support | Errors (use `--danger`) |
| Deep | `--deep`, `--deep-contrast` | One hero per screen: the WOD card, a post image frame, the QR | More than one surface per screen |

## Elements and their parts

### Page and surfaces

| Part | Token |
| --- | --- |
| Page background (body, html, safe-area strip in the store apps) | `--bg` |
| Cards, sheets, dialogs, menus, side panels | `--panel`; raised layers `--panel-raised`; cards in lists `--card` |
| Insets, wells, table stripes, segmented control track | `--panel-muted` |
| Hairlines, dividers, card borders, `<hr>` | `--border` |
| Strong borders, input outlines | `--border-strong` |
| Dialog and sheet backdrop (scrim) | `--scrim` |
| Stacking order of fixed and floating layers (not colours) | `--z-sticky` < `--z-nav` < `--z-drawer` < `--z-modal` < `--z-fullscreen` < `--z-popover` < `--z-toast` (ADR-177) |
| Full-screen media viewers' backdrop | `--scrim-strong` |
| Shadows: chips and toggles / menus and popovers / dialogs and drawers | `--shadow-sm` / `--shadow-md` / `--shadow-lg` |

### Text

| Part | Token |
| --- | --- |
| Body text, headings | `--text` |
| Secondary text, descriptions | `--text-soft` |
| Meta, labels, captions | `--muted` |
| Hints, timestamps, eyebrow labels, disabled text | `--dim` |
| Placeholders (`::placeholder`) | `--placeholder` |
| Links | `--primary` |
| Text selection (`::selection`) | `--selection` with `--selection-text` |
| Highlighted text (`<mark>`, editor highlight) | `--highlight` with `--highlight-text` |
| Code, monospace numbers | font `--font-code` |
| Everything else | font `--font-brand` (Commissioner, self-hosted; Latin, Greek and Cyrillic) |

### Buttons and links

| Part | Token |
| --- | --- |
| Primary button: fill / label / hover / focus ring | `--primary` / `--primary-contrast` / `--primary-strong` / `--focus-ring` |
| Secondary button: fill / border / label | `--panel-raised` / `--border` / `--text` |
| Inverse button (e.g. page header actions) | `--text` fill, `--bg` label |
| Destructive button: fill / label | `--danger` / `--danger-contrast` |
| Disabled | the same tokens at reduced opacity |
| Focus outline (every focusable element) | `--focus-ring` (`:focus-visible`) |

### Form controls

| Part | Token |
| --- | --- |
| Text inputs and textareas: fill / border / text / caret | `--control-bg` / `--control-border` / `--text` / `--primary` |
| Placeholder | `--placeholder` |
| Invalid field border and message | `--danger` |
| Autofilled field (WebKit) | `--control-bg` fill, `--text` text |
| Dropdown (`ui/Select`, ADR-182; native `<select>` is banned by a guard test): trigger / chevron | `--control-bg`, `--control-border`, `--text` / `--muted` |
| Dropdown: open list / group header / hovered or keyboard-active option / chosen option and its ✓ | `--panel`, `--border`, `--shadow-lg` / `--dim` / `--text` at 7% with a `--focus-ring` outline / `--primary` at 14% and `--primary` |
| Date and time pickers (`ui/DateInput`, `TimeInput`, `DateTimeInput`, ADR-182): field / icon / placeholder | `--control-bg`, `--control-border`, `--text` / `--muted` / `--placeholder` |
| Calendar: panel / weekday header / other-month days / today ring / chosen day / Today button / Clear | `--panel`, `--border`, `--shadow-lg` / `--dim` / `--dim` / `--spark` / `--primary` with `--primary-contrast` / `--spark` with `--spark-contrast` / `--muted` |
| Time columns: column track / chosen hour or minute | `--panel-muted` / `--primary` with `--primary-contrast` |
| Checkbox, radio, range, progress, meter | `accent-color: --primary` |
| Custom switches: track on / off / knob | `--primary` / `--border` / `--control-knob` |
| Two-thumb range slider thumbs | `--text` |
| Colour input | `--control-bg`, `--control-border` |
| Search clear button | follows `color-scheme` |
| `<details>` marker | `--muted` |

### Navigation

| Part | Token |
| --- | --- |
| Top bar and bottom tab bar: background / border | `--panel` / `--border` |

### Status and feedback

| Part | Token |
| --- | --- |
| Success text, check-in welcome, door flash | `--success` (`--success-contrast` on fills) |
| Warning text and banners | `--warning` (`--warning-contrast` on fills); banner fill `--warning` mixed into `--panel` |
| Error text, destructive confirmations | `--danger` (`--danger-contrast` on fills) |
| Info | `--info` (`--info-contrast` on fills) |
| Live indicator (class timer) | `--spark` |
| Tinted badges | the status colour mixed into `transparent` or `--panel` with `color-mix()` |

### Data and charts

| Part | Token |
| --- | --- |
| Main series, active bar | `--primary` |
| Categorical series (providers, wellness, analytics) | `--series-1` … `--series-8`; neutral `--series-neutral`; text on a series fill `--on-series` |
| Grid lines / axes / tooltips | `--border` / `--dim` / `--panel` with `--text` |
| Scale levels (Base, Scaled, Rx, Advanced) | `--scale-base`, `--scale-scaled`, `--scale-rx`, `--scale-advanced` |
| Workout types | `--workout-crossfit`, `--workout-strength`, `--workout-gymnastics`, `--workout-aerobics`, `--workout-flexibility`, `--workout-recovery` |
| PR scores and history | `--heat` |
| Anatomy figure: roles, heat map, base and bone | `--anatomy-*` |

### Media

| Part | Token |
| --- | --- |
| Photo and video stage, camera viewfinder, scanner | `--media` |

### Maps

| Part | Token |
| --- | --- |
| Land, background | `--map-land` |
| Water | `--map-water` |
| Parks, woods, green areas | `--map-park` |
| Buildings and their outline | `--map-building`, `--map-road-casing` |

again whenever the member switches between light and dark.

### Native shells and widgets (generated)

| Part | Source |
| --- | --- |
| Android launch screen: background and mark | `@color/palee_background`, `@drawable/palee_mark` (`@color/palee_text`, `@color/palee_primary`) |
| Android widgets: card / title / value / button | `@color/palee_panel` / `palee_muted` / `palee_text` / `palee_primary` with `palee_primary_contrast` |
| Android adaptive icon background | `ic_launcher_background` (Dojo) |
| iOS launch screen | `PaleeBackground` colour set and the `Splash` vector image (light and dark) |
| iOS widgets | `PaleeTheme` (`PaleeWidgets/PaleeTheme.swift`) |
| Offline page in the shells | `www/palee-theme.css` |
| Capacitor splash colour | `palee-theme.json` |

Android `values-night` and iOS dark appearances follow the device's dark
mode; the web view follows the member's own choice.

### Emails, documents and wallet passes rendered by the API

`Palee.BrandPalette.colour/1` (`paper`, `bg`, `text`, `text_soft`, `muted`,
`border`, `primary`, `primary_contrast`, `deep`, `deep_contrast`).

| Part | Token |
| --- | --- |
| Email and receipt page / text / buttons | `paper` / `text` / `primary` with `primary_contrast` |
| Wallet pass (Apple and Google): background / text and labels | `deep` / `deep_contrast` |
| Apple pass icon when the gym has no PNG logo | `primary` |
