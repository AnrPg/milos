# Health declaration

**DRAFT FOR LEGAL REVIEW. Not legal advice. Have a lawyer check it before you use it.**

I declare that:

- My health allows me to exercise.
- I will hand in a health certificate from a GP or cardiologist (a paediatrician for children up to 16), valid for one year, and renew it before it expires.
- I will tell the box if anything about my health changes in a way that affects exercise.

The box keeps only the dates and the file of the certificate, and only for as long as needed.
